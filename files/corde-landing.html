Questions

Does my voice leave my computer?

No. Transcription runs locally with Faster-Whisper, so audio is never sent anywhere.

Which apps does it work with?

Any app that accepts keyboard input. It was designed for terminals and CLI agents like Claude Code.

How accurate is it?

It uses Whisper models in an optimized runtime. Smaller models are faster, and you can pick a larger one for more accuracy.
